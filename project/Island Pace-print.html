UX Rationale
The homepage answers the core question — "What can I join this weekend?" — above the fold. Dark hero creates an immediate premium feel. Weekend band is persistent so users never have to scroll to find urgency.
Section order mirrors user intent: immediate (this weekend) → medium-term (events) → discovery (clubs). Submit CTA at bottom catches organisers naturally after they've seen the value.

Filterable session discovery · Date-grouped · Real-time count
Filter System
→Chip rail: Sport · Date · Location
→Difficulty · Beginner Friendly
→No Drop · Coffee Stop
→Tourist Friendly · Women Friendly
→Advanced panel via "Filter ⧉"
Date Grouping UX
Sessions grouped by date with a ruled-line separator. "THIS WEEKEND" accent label appears for Sat–Sun to surface urgency. Groups collapse once past.

04 — Activity Detail
Activity Detail
Most important page · "Is this for me? How do I join?"
Above The Fold
Hero shows: badge strip → title → date/time/location. Quick-stats card immediately below: distance, pace, duration, participant count. All decision-critical info without scrolling.
Sticky CTA Strip
Permanently pinned to bottom. Three actions always accessible:
I'm Interested · WhatsApp · Share. User never loses the action even when reading safety notes.
Page Sections
1.Badge strip + Title hero (dark)
2.Quick stats card (3-up grid)
3.Route map placeholder + endpoints
4.Suitability badges + description
5.Organiser card + contact buttons
6.Safety notes
Visibility Controls
→Activity: Public / Unlisted / Private
→Attendees: Count only / Names / Hidden
✓Default: Public + count only

05 — Submit Activity Form
Submit Activity
3-step progressive form · Mobile-first · Feels fast
Step 1 — Core Details
→Activity title
→Type: Ride / Run / Triathlon
→Date + Start time
→City / area (dropdown)
→Start location
→Difficulty (4-way toggle)
Step 2 — Session Details
→Distance + Duration
→Pace / average speed
→Route link (Strava/Komoot)
✓Coffee Stop (toggle)
✓No Drop (toggle)
→Beginner / Women / Tourist friendly
Step 3 — Organiser
→Organiser name / club
→WhatsApp contact
→Strava club link (optional)
→Visibility: Public / Unlisted / Private
→Attendee visibility dropdown
Progress Stepper
Three-segment progress bar. No numbers — just a clear sense of position. Each step is a single screen scroll.
UX Principles
→No step feels long — max 6 fields per screen
→Toggles for binary features (not checkboxes)
→Optional fields collapsed under "Add more details"
→Sticky Continue/Submit button always visible
✓Goal: submit complete in under 2 minutes
